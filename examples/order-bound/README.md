# 第一次接手一个数学草稿

安装并启用插件后，把本目录复制到你自己的项目内的一个新工作目录，在 DSH 中明确打开这个目录并新建会话。目录内包含普通文字草稿、对应的 Lean 源码和工具链版本文件；需要本机已有 Lean 4.22.0，不需要 Mathlib。

直接发送：

```text
请阅读 problem.md 和 OrderBound.lean，接手并核验这段草稿，说明已有结果和接下来可以研究什么。
```

观察回答是否解释了不等式的前提、等号条件，以及 Lean 是否实际核验了对应命题。上界 `a + b ≤ 2b` 使用 `a ≤ b`；等号的充要条件对所有整数成立，不需要这个顺序前提。核验记录会保存在当前工作区的 `.dsh/math/`，后续对话可以接着推进。

想试一次目标变化，可以继续发送：

```text
如果不再假设 a ≤ b，原来的上界还成立吗？请给出依据，并说明已有的等号条件是否仍成立。
```

这个变化应当区分两条结论：上界失去保证，等号条件仍成立。旧证明及其原有前提应当保留，新的研究目标另行记录。例题只用于熟悉接手草稿、核验和继续讨论的流程，不评估数学难度。
